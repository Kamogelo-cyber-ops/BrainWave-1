# BrainWave

A collaborative task and study management app with built-in gamification — track tasks, set reminders, collaborate with others, and earn badges for progress.

Team project. I contributed as part of the development team (contributions made outside this GitHub account, so they may not show in the commit history here).

# ✨ Features
✅ Task management (TaskItem)
⏰ Reminders for upcoming tasks/deadlines (Reminder)
🤝 Collaboration between users on shared tasks (Collaboration, UserCollaboration)
🏅 Badges and achievements to reward progress (Badge, UserBadge)
📤 Export functionality for your data (Export)
👤 User accounts and profiles (User)
# 🛠️ Tech Stack
Language: C#
